Features

Output monitoring, solved

Hallucination detection

LLM-as-judge scoring compares outputs against your provided context and ground-truth documents. Configurable thresholds per dimension.

Brand safety scoring

Configurable rules plus LLM-as-judge evaluation for tone, voice, terminology, and brand guideline compliance.

Real-time blocking

Smart alerting

Python TypeScript 
from gatekeeper import Gatekeeper
from openai import OpenAI

# Wrap your existing OpenAI client
client = Gatekeeper(
    openai_client=OpenAI(),
    rules={
        "hallucination": {"threshold": 70},
        "brand_safety": {"threshold": 80},
        "block_below": 50,
    }
)

# Use exactly like OpenAI — Gatekeeper intercepts every response
result = client.chat.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "..."}],
)

# result.response — the AI output (if above threshold)
# result.scores — {hallucination: 92, brand_safety: 88, ...}
# result.blocked — True if any dimension below threshold
